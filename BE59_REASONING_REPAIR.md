## What changed

Evidence now comes from separately identified reviewed record bodies and owner corrections. Workflow instructions, fictional test input and executive personality are not quotation sources. The original full-plan guard accepts an explicit source map; its original default and existing structured meetings remain unchanged.

The application now supplies a disclosed first-user workflow: one five-minute tool check with exact fictional notice text and observable results, then one ten-minute review of existing contact records. Unknown identity/status requires checking names, dates and replies. A recent reply requires checking own-live-case evidence and reviewing a conditional unsent invitation. Silence requires reviewing another already permitted conversation or recording a blocker. These estimates and routes are code policy, not inferred facts or independent executive reasoning. No real tool checks, contact, spending or product changes occur during generation.

Success requires a willing seller's own current live-case test and feedback on diagnosis, unsupported details and usefulness. Private-review deadlines begin when checks start; reply deadlines begin only if the owner chooses to send a draft. A typed unresolved question supplies the pivotal fact and two conditional branches. Already supplied contact status cannot be presented as missing. Proposed outreach remains owner-only, conditional and accompanied by an actual not_sent draft with redaction and feedback questions.

The full correction is preserved verbatim by the application, independently of which evidence the model selects. This is an explicitly declared source snapshot, not a repair of failed raw model output. The explanation helper is role-neutral; registered executive identities/personas are untouched. Canonical persona remains comparison metadata, but is omitted from this helper's model input. The model still supplies selected evidence, alternatives and pivotal explanation; these require semantic review.
