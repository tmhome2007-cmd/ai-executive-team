## What we learned

missed negative facts and contaminated a summary with unrelated return-policy
instructions. Exact supplied facts, server-rendered function steps where clearly
labelled, separated reply instructions and bounded repairs improved the supported
examples. Failed drafts remain evidence. The reply still groups a known no-refund
fact under unknowns; the greenhouse summary still includes an unnecessary
self-evaluation note. These presentation issues remain visible for usefulness
review rather than being hidden by a contract pass.

Early browser checks caught integration issues before the final audit. Shared
navigation helpers made desktop/mobile destinations and hidden-tab behavior
consistent. The newly collapsed feedback panel required an explicit open action in
its browser test. Fractional timestamp ordering was fixed while preserving legacy
bytes and execution-order validation. A final real demo shutdown check exposed
duplicate termination that left stale runtime metadata. The launcher now terminates
only live owned children once, waits for them, and removes only its own metadata;
regression tests and a real shutdown passed before the complete audit was rerun.
Local identity resolution required handling
the SDK's native/root and /v1 endpoint forms, and never inventing legacy digests.

acceptance for every deliverable or a merge instruction. `./company review` now
