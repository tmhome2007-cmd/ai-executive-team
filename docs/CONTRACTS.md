Dated technical/research record; results and limitations apply to the versions described. Use [the README](../README.md) for current status and planning.

|---|---|---|---|

Use cases: owner runs a fictional benchmark; compares matching rubrics; selects an older benchmark prompt; reviews skill evidence; downloads private artifacts; diagnoses an interrupted local run; reviews queued sources; corrects memory; views recorded activity in 3D.

## Invariants and recovery

- Never infer approval from model text, board status, benchmark score, skill status or animation. Reuse existing approval, treasury and capability ledgers.
- Benchmark attempts retain dataset/checker/rubric hashes, exact prompt snapshot, model digest where available, generation configuration and outcome. Transport errors and interrupted attempts count as failures/incomplete work, not successes. Automated checks measure narrow contracts; no AI judge or owner assessment is invented.
- Compare runs only with identical dataset and checker/rubric. Prompt/model changes are visible comparison dimensions. Rollback selects a preserved prompt version; it never rewrites earlier results or silently changes production prompts.
- Skills are immutable versions; revocation blocks future selection, while earlier executions and source reviews remain visible. Two accepted examples do not establish general competence.
- Artifacts are plain text/Markdown initially. Owner authentication, private response headers, bounded size, confined paths and symlink rejection apply. Generated bytes expire after 30 days under the existing artifact policy; durable hashes/review/provenance remain and expired content is explicitly unavailable. Backups obey existing encrypted-storage and restore procedures; deletion must not promise removal from retained backups.
- Inspection defaults to metadata, not raw prompts, secrets or private source excerpts. Local generation may retry through existing claims; uncertain external effects require reconciliation. Laptop sleep/offline means pending work, not completed work.
- Knowledge retrieval excludes corrected/expired facts from current context, while preserving historical provenance. Suggested source URLs are not fetched evidence.
- Preserve approved identities/personas; movement in the office is fictional illustration, not proof of productivity.

## Reuse and privacy

This increment uses Python standard-library code and existing local Ollama; no upstream code/assets, new runtime dependencies or paid services are imported. Before future reuse record upstream commit/file, exact license, notices, asset/model rights, dependencies and vulnerability findings. Do not embed n8n or enterprise-only code on the strength of a repository description.

Budget/permitted loss remain €0. No publication, customer contact, paid inference or cloud transmission. New cloud/paid authority requires an explicit owner decision.
